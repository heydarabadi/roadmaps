## تمرین فصل

سناریوی ایجاد سفارش را یک‌بار با پاسخ هم‌زمان API و یک‌بار با صف پیام طراحی کن. رفتار timeout، retry، تکرار پیام، نسخهٔ قرارداد و مشاهده‌پذیری را بنویس.
