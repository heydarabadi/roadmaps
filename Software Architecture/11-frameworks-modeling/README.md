# فصل ۱۱: چارچوب‌ها و مدل‌سازی

چارچوب، اصطلاح مشترک و روش سازمان‌دهی تصمیم‌ها را فراهم می‌کند. چارچوب جای شناخت مسئله را نمی‌گیرد و لازم نیست تمام خروجی‌های آن برای هر پروژه تولید شوند. قالب و میزان رسمیت را با مقیاس، مقررات و مخاطب تنظیم کن.

## تمرین فصل
