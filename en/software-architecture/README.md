# Software Architecture — English Edition

This folder mirrors the Persian course at the parent directory. It contains a chapter-by-chapter, self-study guide based on the Software Architect roadmap, with expanded lessons, worked examples, exercises, answer guides, quizzes, and references.

Start with the [study guide and index](00-index.md). The [glossary](glossary.md) explains recurring terms. Every chapter links to its topic lessons. The [capstone](15-capstone-assessment/01-ecommerce-capstone/README.md) applies the material to one continuing e-commerce system.

The linked articles are curated for depth and follow-up reading. The core explanations are intended to stand on their own; consult primary documentation for current product behavior, standards, and version-specific details.
