# Chapter 09 — Cloud Design Patterns

[فارسی](../../09-cloud-design-patterns/README.md)

This chapter groups cloud patterns into implementation, data management, and messaging. The lessons explain the problem each pattern addresses, its shape, the trade-offs it introduces, and the conditions under which it becomes harmful.

## Topics

- [Design and implementation patterns](25-design-implementation-patterns/README.md)
- [Cloud data patterns](26-cloud-data-patterns/README.md)
- [Cloud messaging patterns](27-cloud-messaging-patterns/README.md)

## Learning outcome

You should be able to choose a pattern from a stated constraint, explain its operational cost, and tell when a simpler design would be safer.
