## شیوهٔ استفاده

برنامه برای روزی حدود ۶۰ تا ۹۰ دقیقه، پنج روز در هفته طراحی شده است؛ این برآورد است، نه ضرب‌الاجل. هر هفته یک جلسهٔ بازخوانی و یک خروجی عملی دارد. اگر quiz را با کمک answer key حل کردی، پاسخ را ببند و دوباره با توضیح از حافظه جواب بده. لازم نیست برای ورود به هفتهٔ بعد نمرهٔ عددی بگیری؛ مهم است بتوانی ایده و خطاهای رایج را توضیح دهی.

برای کار آفلاین، فایل‌های README محلی، Go toolchain نصب‌شده و نمونه‌های code fence کافی‌اند. لینک‌های بیرونی برای بررسی syntax نسخهٔ جدید، API مرجع و مطالعهٔ عمیق‌تر هستند؛ لازم نیست به ترتیب درس‌ها آن‌ها را بخوانی.

## فاصله‌گذاری و ارزیابی

هر جمعه، واژه‌های هفته را از [واژه‌نامه](%D9%88%D8%A7%DA%98%D9%87%E2%80%8C%D9%86%D8%A7%D9%85%D9%87.md) مرور کن و از حفظ به این چهار سؤال جواب بده: مفهوم چیست؟ کجا مناسب است؟ failure mode چیست؟ یک مثال واقعی/تستی چیست؟ ۲۴ ساعت بعد و یک هفته بعد quizهای غلط را دوباره حل کن. پاسخ را توضیح بده؛ حفظ شمارهٔ جواب نشانهٔ یادگیری نیست.
