# کتابخانهٔ منابع

**زبان:** فارسی · [English](../en/08-resources/README.md)

## تفسیر منابع

- راهنمای شرکت، سیاست همان سازمان است و قانون همگانی نیست.
- پژوهش‌ها به نمونهٔ خاص تعلق دارند؛ همبستگی لزوماً علیت نیست.
- postmortem رسمی برای شرح رخداد اول‌دست است، ولی درس پیشنهادی این دوره استنباط آموزشی است.
- مقاله‌های فارسی از نظر کیفیت و تاریخ به‌روزرسانی متفاوت‌اند؛ موضوع امنیتی را با OWASP تطبیق بده.
