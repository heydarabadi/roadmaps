## ترتیب پیشنهادی

1. پیش‌نیازها و تعریف‌ها را بخوان.
2. مثال هر تاپیک را دستی اجرا کن.

## فرایند انتخاب الگو

۱) نوع خروجی را تشخیص بده: یک جواب، همهٔ جواب‌ها، بهترین مقدار یا زیرآرایهٔ پیوسته؟ ۲) محدودیت n را بخوان. ۳) baseline بساز. ۴) تکرار یا ساختار را پیدا کن: prefix، window، sorted order، subproblem overlap، monotone choice، constraintها. ۵) invariant بنویس. ۶) پیچیدگی را حساب و edge case را اضافه کن.

| نشانهٔ صورت مسئله | الگوی محتمل | شرطی که باید ثابت شود |
|---|---|---|
| همهٔ ترکیب‌های معتبر | backtracking | state/undo و pruning معتبر |
| زیرمسئله‌های تکراری و بهینه‌سازی | DP | state و recurrence کامل |

| kاُمین رتبه | quickselect/heap | rank convention |
| بازه‌های overlap | merge intervals | endpoint semantics |

## آموزش گره‌های والد در نقشهٔ رسمی

این بخش عنوان‌های گروهی نقشه را نیز پوشش می‌دهد؛ برای درس مستقل هر برگ، README تاپیک را باز کن.

## تاپیک والد نقشه: Problem Solving Techniques

### آموزش

الگوهای حل مسئله میان ورودی، قیود و عملیات پرتکرار پیوند می‌زنند: recursion، divide-and-conquer، greedy، backtracking، DP و الگوهای اشاره‌گر/پنجره.

**روش انتخاب/اجرا:** قیود ورودی را بخوان؛ baseline درست بنویس؛ الگوی کاهندهٔ فضای جست‌وجو را انتخاب؛ invariant/اثبات را روشن کن؛ با edge case و complexity تأیید کن.

**پیچیدگی و مبادله:** Brute force ممکن است نمایی یا چندجمله‌ای باشد؛ الگوهایی مثل DP یا دو اشاره‌گر می‌توانند با فرض مناسب به O(n) یا تعداد stateها کاهش دهند.

**تجربهٔ عملی:** الگوها در مصاحبه، پردازش بازه، تحلیل stream و حل مسائل زمان‌بندی/محدودیت استفاده می‌شوند.

**دام رایج:** از روی اسم مسئله الگو را حدس نزن؛ شرط کاربرد و اثبات درستی باید با مسئله جور باشد.

### آزمون کوتاه با پاسخ

1. **پرسش:** قدم اول بعد از فهم صورت چیست؟
   **پاسخ:** قیود، ورودی/خروجی، حالت‌های مرزی و یک baseline ساده را تعریف کن.
2. **پرسش:** چه زمانی DP کمک می‌کند؟
   **پاسخ:** زیرمسئله‌های هم‌پوشان و رابطهٔ بهینهٔ معتبر وجود داشته باشد.
3. **پرسش:** چه زمانی greedy مجاز است؟
   **پاسخ:** وقتی انتخاب محلی بهینه با استدلالی مثل exchange argument جواب کلی را تضمین کند.


## آزمون جمع‌بندی فصل

۱. چرا وجود زیرمسئلهٔ هم‌پوشان به DP اشاره می‌کند؟ محاسبات تکراری قابل cache هستند. ۲. greedy را بدون proof می‌توان پذیرفت؟ خیر. ۳. sliding window روی جمع اعداد منفی همیشه درست است؟ خیر؛ monotonicity ممکن است از بین برود. ۴. backtracking چه باید undo کند؟ تمام state تغییرکرده. ۵. دو heap چه medianی را سریع می‌دهند؟ ریشه‌های نیمهٔ پایین/بالا. ۶. چندریسمانی کدام دو معیار را جدا می‌کند؟ work و span.

## معیار عبور

برای سه مسئلهٔ مشابه، یک مثال نقض برای الگوی نادرست بساز و شرطی که الگوی درست را معتبر می‌کند توضیح بده. صرف نام‌گذاری الگو، یادگیری نیست.
