# فصل ۱: نقش معمار و مبانی معماری

معمار تصمیم‌های پرهزینه و اثرگذار بر ویژگی‌های کیفی سیستم را پیدا می‌کند، گزینه‌ها را با ذی‌نفعان می‌سنجد، دلیل تصمیم را ثبت می‌کند و کمک می‌کند تیم آن را به‌صورت تدریجی اجرا و بازبینی کند. عنوان شغلی به‌تنهایی اختیار یا پاسخ‌گویی یکسانی را تضمین نمی‌کند.

## تمرین فصل

سامانهٔ فروشگاهی فرضی را در نظر بگیر. سه ذی‌نفع اصلی، سه نیازمندی کیفی قابل‌اندازه‌گیری، یک تصمیم معماری پرریسک و یک روش مستندسازی متناسب با هر مخاطب را مشخص کن.
