# Chapter 01 — System Design Foundations

[فارسی](../../01-foundations/README.md)

This chapter introduces a repeatable way to turn a product request into a measurable architecture. It distinguishes performance from scalability, latency from throughput, availability from consistency, and then develops consistency patterns, CAP, and availability arithmetic.

## Study order

2. [Performance and scalability](02-performance-scalability/README.md)
3. [Latency and throughput](03-latency-throughput/README.md)
4. [Availability and consistency](04-availability-consistency/README.md)
5. [Consistency patterns](05-consistency-patterns/README.md)
6. [The CAP theorem](06-cap-theorem/README.md)
7. [Availability and downtime math](07-availability-math/README.md)

## Learning outcome

You should be able to state a design trade-off with its assumptions, describe a failure mode, and identify the evidence needed to judge whether a solution works.
