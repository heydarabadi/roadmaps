# راهنمای دورهٔ خودآموز MongoDB

> **نسخهٔ انگلیسی:** [English edition](../../en/mongodb/course-overview.md).

## این دوره برای چه کسی است؟
برای کسی که آشنایی اولیه با برنامه‌نویسی دارد و می‌خواهد MongoDB را از صفر تا طراحی و نگهداری production یاد بگیرد. نیازی به خواندن لینک‌های بیرونی برای فهم درس‌های پایه نیست؛ هر درس مفهوم، مثال و تمرین را داخل خودش دارد. لینک‌ها برای مرجع نسخه‌ای و مطالعهٔ بیشترند.

## پیش‌نیازها
- آشنایی مقدماتی با متغیر، object، array و تابع در یک زبان برنامه‌نویسی.
- آشنایی پایه با JSON و HTTP مفید است، اما فصل اول مرور لازم را دارد.
- برای تمرین، mongosh و MongoDB Server محلی یا deployment آزمایشی لازم است.

## ترتیب یادگیری
1. فصل ۱: مدل سند، BSON، Atlas و ابزارها.
2. فصل ۲: CRUD، filter، update، cursor و concernها.
3. فصل ۳: schema، embedding و reference.
4. فصل ۴: index، explain، aggregation و search.
5. فصل ۵: transaction، replica set، backup، sharding و ظرفیت.
6. فصل ۶: authentication، authorization، encryption و audit.
7. فصل ۷: driver، connector، change stream و ابزار عملیات.
8. پروژهٔ capstone را با queryها و معیارهای نوشته‌شده تحویل دهید.

## روش مطالعهٔ هر درس
- ابتدا هدف و پیش‌نیاز را بخوانید.
- مثال را در database آزمایشی اجرا کنید و هر خط را با صدای بلند توضیح دهید.
- خروجی خودتان را با بخش مثال مقایسه کنید؛ مقدار ObjectId و زمان دقیق ممکن است متفاوت باشد.
- تمرین را بدون نگاه به پاسخ انجام دهید و سپس پاسخ‌نامه را بررسی کنید.
- اگر جواب غلط است، علت را در مدل داده، نوع BSON، filter یا خطای نسخه پیدا کنید؛ فقط فرمان را حفظ نکنید.

## ابزارهای تمرین
برای شروع local مناسب است. Atlas هم می‌تواند محیط آزمایشی باشد؛ user جدا، secret امن و network restriction لازم است. هیچ فرمان حذف/بازنویسی گسترده را روی دیتابیس واقعی اجرا نکنید. دادهٔ تمرین در namespace جدا با نام learning نگه دارید.

## معیار تسلط
برای هر موضوع بتوانید تعریفش کنید، یک مثال تازه بسازید، trade-off را توضیح دهید، خطای رایج را تشخیص دهید و بگویید چه چیزی را باید در production اندازه‌گیری یا monitor کرد.

## نسخه و محدودیت
دستورها برای آموزش عمومی نوشته شده‌اند. قابلیت‌های Atlas، Enterprise، driver و server ممکن است نسخه/edition خاص بخواهند. برای اتصال production، کلیدهای امنیتی یا پارامترهای نسخه‌محور، راهنمای رسمی جاری را بررسی کنید. توضیح پایه در همین دوره آمده و لینک مرجع مکمل آن است.

## چطور از درس‌ها استفاده کنید؟

هر موضوع سه نوع یادگیری دارد:
1. **فهم:** مفهوم را بدون نگاه‌کردن به کد توضیح دهید.
2. **اجرا:** مثال را در پایگاه یادگیری اجرا و خروجی را پیش‌بینی کنید.
3. **تصمیم:** بگویید چه وقت از این قابلیت استفاده نمی‌کنید و چه trade-offی دارد.

اگر فقط کد را کپی کنید، تفاوت بین رفتار driver، server و shell روشن نمی‌شود. دستورهای mongosh را از API زبان برنامه جدا نگه دارید. برای مباحثی که روی version/edition اثر دارند، درس خودکفا است ولی لینک رسمی برای تأیید محیط واقعی باقی می‌ماند.

## نقشهٔ آزمون

هر درس ده پرسش پاسخ‌دار دارد. اول پنج سؤال اصلی را بدون نگاه به پاسخ حل کنید؛ بعد پنج پرسش تکمیلی را برای تصمیم‌گیری و خطایابی انجام دهید. برای خودسنجی، هر پاسخ باید شامل دلیل باشد، نه فقط نام operator.
