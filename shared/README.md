# Shared repository material

This directory is for files that are language-neutral and used by more than one learning path.

## What belongs here

- Cross-course reference material that applies to at least two courses.
- Reusable assets that do not belong to one language edition or one course.
- Repository-wide conventions that help maintain shared content.

## What stays elsewhere

- Persian lessons and course-specific references stay under `fa/<course-slug>/`.
- English lessons and course-specific references stay under `en/<course-slug>/`.
- Plans and specifications stay under `docs/superpowers/`.
- Historical task reports and review artifacts stay under `internal/workflow-artifacts/`.
- Maintenance scripts stay under `tools/` or `internal/scripts/`, according to whether they are intended for regular repository use.

Add a shared reference only when multiple courses use it. A reference that supports one technology or one lesson belongs beside that course's material.
