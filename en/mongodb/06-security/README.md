# Chapter 6 — Security

> **Persian edition:** [Read the Persian version](../../../fa/mongodb/06-security/README.md).

## Lessons

- [MongoDB security in layers](security/README.md) — combine identity, network, encryption, logging, and recovery controls.
- [Authentication and RBAC](authentication-rbac/README.md) — separate identity from permissions and grant least privilege.
- [Enterprise authentication](enterprise-auth/README.md) — compare SCRAM, X.509, Kerberos, and LDAP, including current deprecations.
- [Encryption](encryption-detail/README.md) — distinguish TLS, storage encryption, CSFLE, and Queryable Encryption.
- [Auditing](audit-detail/README.md) — capture security-relevant actions while protecting sensitive log data.

## Practice

Create an access matrix for the application, analyst, backup job, and operator. For each identity, list the databases and actions it truly needs.
