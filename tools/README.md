# Repository tools

This folder holds repository-level tools intended for maintainers.

## Legacy translator

`translate_architecture_en.legacy.ps1` is retained as a historical artifact from the former mixed-language layout. It stops immediately with a notice because its broad output behavior could overwrite the maintained `en/` course tree. Do not remove the guard or use the script to generate course files. Maintain paired pages directly under `fa/` and `en/`.
