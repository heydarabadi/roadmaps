# Chapter 06 — Asynchronous Processing and Messaging

[فارسی](../../06-async-and-messaging/README.md)

This chapter uses background jobs, queues, and streams to separate request intake from work completion. It covers delivery guarantees, consumer scaling, backpressure, retries, dead-letter handling, and idempotency.

## Topics

- [Background jobs](19-background-jobs/README.md)
- [Queues, streams, and backpressure](20-queues-streams-backpressure/README.md)
- [Messaging patterns](21-messaging-patterns/README.md)
- [Idempotency](22-idempotency/README.md)

## Learning outcome

You should be able to design a message lifecycle from production to acknowledgement and recovery, including what happens when messages are delayed, duplicated, or processed out of order.
