# کتابخانهٔ منابع فارسی و انگلیسی

این فهرست کنار هر درس، منابع مستقیم‌تر همان موضوع را هم دارد. انتخاب‌ها از roadmapهای رسمی، مستندات استاندارد/فروشنده، راهنماهای مهندسی شناخته‌شده و چند منبع فارسی موضوعی انجام شده‌اند. فهرست، همهٔ وب را دربرنمی‌گیرد؛ اینترنت پیوسته تغییر می‌کند و «همهٔ منابع» قابل‌احراز نیست. برای یادگیری قابل‌پیگیری، منبع‌های اولیه و مثال‌های عملی را برگردانده‌ام.

## تجربه‌های واقعی منتشرشده

این‌ها گزارش‌های خود سازمان‌ها/پژوهشگران‌اند؛ برای سیستم دیگری باید شرایط و محدودیت‌ها را دوباره سنجید.

- [Netflix: بازسازی pipeline ویدئو با Microservices](https://netflixtechblog.com/rebuilding-netflix-video-processing-pipeline-with-microservices-4e5e6310e359) — جداسازی پردازش و گام‌های pipeline.
- [Netflix: مهاجرت cloud](https://about.netflix.com/en/news/completing-the-netflix-cloud-migration) — زمینهٔ تحول زیرساخت و محدودیت‌های معماری قبلی.
- [Netflix: نقشهٔ زندهٔ وابستگی سرویس‌ها](https://netflixtechblog.com/from-silos-to-service-topology-why-netflix-built-a-real-time-service-map-0165ba13a7bc) — نیاز دیدن dependency در سامانهٔ بزرگ.
- [Uber: Edge Gateway](https://www.uber.com/us/en/blog/gatewayuberapi/) — مدیریت چرخهٔ API و کاهش round trip.
- [Uber: Real-time Data Infrastructure](https://arxiv.org/abs/2104.00087) — تجربهٔ پژوهشی/مهندسی زیرساخت دادهٔ زنده.
- [Google SRE: SLOها](https://sre.google/sre-book/service-level-objectives/) — کیفیت خدمت و error budget.
- [AWS: Event-Driven Architecture](https://aws.amazon.com/event-driven-architecture/) — producer، router، consumer و trade-offهای تحویل و ordering.

## یادداشت دربارهٔ منابع

مستندات رسمی برای رفتار جاری محصول و استاندارد مرجع‌اند؛ مقالهٔ شرکتی تجربهٔ یک محیط خاص را شرح می‌دهد؛ ترجمه و نوشتهٔ فارسی برای یادگیری سریع‌تر مفید است ولی باید نکته‌های حساس را با منبع اصلی مقابله کرد. لینک‌های نسخه‌دار و مجوز/قیمت فروشنده‌ها ممکن است تغییر کنند.
