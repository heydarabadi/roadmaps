# فصل ۶: معماری داده و تحلیل

داده تنها «جداول» نیست: مدل دامنه، مالکیت، کیفیت، نگهداری، حریم خصوصی، جریان تغییر، سازگاری و مصرف تحلیلی باید با هم طراحی شوند. انتخاب فناوری ذخیره‌سازی را از الگوی دسترسی و ضمانت‌های لازم شروع کن.

## تمرین فصل

برای سفارش‌ها، سبد خرید و تحلیل رفتار مشتری، مدل عملیاتی و تحلیلی را جدا کن. نیازهای سازگاری، پرس‌وجو، بازیابی، نگهداری و هزینه را ثبت کن.
