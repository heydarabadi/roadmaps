This folder contains a chapter-based course organized around the [roadmap.sh Software Design and Architecture roadmap](https://roadmap.sh/software-design-architecture). The lessons, examples, exercises, and quizzes are written for this course rather than copied line by line from the roadmap.

## Suggested route

1. Clean code and programming paradigms
2. Object-oriented programming and design principles
3. GoF patterns and architectural principles
4. Architectural styles and architectural patterns
5. Enterprise application patterns

Start with the [complete course index](00-index.md). Each chapter includes an integrated lesson, standalone topic pages, examples, trade-offs, exercises, and quizzes with answers. Outside sources are optional further reading, not prerequisites for understanding the lessons.
