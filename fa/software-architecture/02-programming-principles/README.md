# فصل ۲: زبان‌ها و اصول طراحی

معمار لازم نیست در همهٔ زبان‌ها متخصص روز باشد؛ باید هزینهٔ نگهداری، قابلیت تیم، اکوسیستم، عملکرد، امنیت، دسترس‌پذیری مهارت و تناسب زبان با بار کاری را بسنجد. اصول طراحی ابزار گفت‌وگو و کاهش وابستگی ناخواسته‌اند، نه فهرست قوانین برای امتیاز گرفتن.

## تمرین فصل

برای یک سامانهٔ پرداخت، یک سرویس گزارش‌گیری و یک رابط وب، زبان‌های ممکن را بر اساس مهارت تیم، اکوسیستم، محدودیت کارایی و هزینهٔ عملیات مقایسه کن. تصمیم را در یک پاراگراف مستدل بنویس.

منابع پایه: [Software Design & Architecture roadmap](https://roadmap.sh/pdfs/roadmaps/software-design-architecture.pdf)، [مبانی معماری نرم‌افزار به فارسی](https://www.alirostami.com/software-architecture/).
