[فارسی](../../../fa/system-design/03-network-edge-communication/README.md)

This chapter follows requests through DNS, content delivery, load balancing, and application protocols. Each layer can improve reachability or performance, but also adds caching, routing, timeout, security, and debugging behavior.

## Topics

- [DNS](10-dns/README.md)
- [Content delivery networks](11-cdn/README.md)
- [Load balancing](12-load-balancing/README.md)
- [Communication protocols](13-protocols/README.md)

## Learning outcome

You should be able to trace one request from a client to a service, explain how it is resolved and routed, and identify what each network layer can and cannot guarantee.
