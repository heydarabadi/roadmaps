# فصل: تحمل خرابی و تکثیر

Failover و replication را همراه RTO/RPO، تأخیر تکثیر و آزمون بازیابی می‌آموزی.

## روش مطالعه

1. موضوع‌ها را به‌ترتیب بخوان.
2. قبل از پاسخ‌نامه، آزمون کوتاه هر درس را حل کن.
3. تمرین را برای پروژه یا دامنه‌ای که می‌شناسی بازنویسی کن.
4. یک تصمیم را با فرض، عدد، رفتار شکست، هزینه و معیار پایش توضیح بده.

## خروجی مورد انتظار

بتوانی trade-off را در قالب یک تصمیم مستدل بیان کنی، failure mode را توصیف کنی و بدانی چه شواهدی برای تأیید راه‌حل لازم است.
