# کتابخانهٔ منابع تکمیلی

این کتابخانه منابع منتخب را بر پایهٔ فصل‌های دوره گروه‌بندی می‌کند. هدف، جمع‌آوری «تمام اینترنت» نیست: منابع اصلی و فنی، مستندات رسمی، کاتالوگ‌های شناخته‌شده، مقاله‌های نویسندگان اثرگذار، چند مطالعهٔ موردی شرکت‌ها و منابع فارسیِ قابل استفاده انتخاب شده‌اند. لینک‌ها برای تعمیق یا مقایسهٔ دیدگاه‌ها هستند؛ متن درس‌های این مجموعه برای یادگیری مبانی کافی طراحی شده است.

هنگام خواندن هر مقاله، این پرسش‌ها را پاسخ بده: مسئله و محدودیت چه بود؟ چه گزینه‌هایی مقایسه شدند؟ نتیجه برای چه مقیاسی گزارش شده؟ هزینه یا عارضهٔ جانبی چیست؟ آیا نویسنده تجربهٔ موردی را گزارش می‌کند یا یک قاعدهٔ عمومی را ادعا می‌کند؟ تجربهٔ یک شرکت را بدون مقایسهٔ workload، تیم و محدودیت‌هایش نسخه‌برداری نکن.
