# کتابخانهٔ مسیرهای یادگیری

این مخزن یازده دورهٔ آموزشی را به دو زبان فارسی و انگلیسی نگهداری می‌کند. هر دوره در دو درخت زبانی پوشهٔ متناظر دارد و فصل‌ها، درس‌ها، مثال‌ها، تمرین‌ها و منابع خودش را در همان‌جا نگه می‌دارد.

- [ورود به فهرست فارسی](fa/README.md)
- [Open the English catalog](en/README.md)

برای آشنایی با ساختار پوشه‌ها و شیوهٔ مطالعه، فهرست زبان دلخواهت را باز کن.
