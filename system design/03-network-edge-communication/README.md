# فصل: شبکه، لبه و ارتباط

DNS، CDN، توزیع بار و پروتکل‌ها مسیر درخواست را از کاربر تا سرویس شکل می‌دهند.

## روش مطالعه

1. موضوع‌ها را به‌ترتیب بخوان.
2. قبل از پاسخ‌نامه، آزمون کوتاه هر درس را حل کن.
3. تمرین را برای پروژه یا دامنه‌ای که می‌شناسی بازنویسی کن.
4. یک تصمیم را با فرض، عدد، رفتار شکست، هزینه و معیار پایش توضیح بده.
