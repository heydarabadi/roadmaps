# آزمایشگاه عملی: کاتالوگ فارسی فروشگاه

[English version](../../../../en/elasticsearch/labs/catalog/README.md)


این آزمایشگاه یک دادهٔ نمونهٔ ثابت را در فصل‌های مختلف به‌کار می‌برد. هیچ داده یا سرویس بیرونی لازم نیست؛ درخواست‌ها را در Kibana Dev Tools → Console روی cluster آزمایشی اجرا کن. پیش از اجرا، endpoint و نام index را بررسی کن. درخواست DELETE فقط برای `products-lab-v1` است.

## فایل‌ها

- [درخواست‌های Kibana Console](catalog-console.http) — ساخت index، درج ده کالا و queryهای نمونه.
- [تمرین‌ها و پاسخ تشریحی](exercises.md) — تمرین مرحله‌ای از mapping تا Search، aggregation و pagination.

## مسیر اجرا

1. در Kibana Console همهٔ درخواست‌های `catalog-console.http` را بخوان؛ هر درخواست را جداگانه اجرا کن تا خروجی همان مرحله را ببینی.
2. ابتدا `PUT /products-lab-v1` را اجرا کن و mapping را با `GET /products-lab-v1/_mapping` بخوان.
3. درخواست Bulk را اجرا کن؛ پاسخ باید `errors: false` نشان بدهد. در صورت true بودن، itemهای خطادار را جدا پیدا کن.
4. queryهای بعدی را اجرا کن و پیش‌بینی‌ات را پیش از دیدن پاسخ بنویس.
5. تمرین‌های [فایل تمرین](exercises.md) را انجام بده و بعد پاسخ‌ها را باز کن.

## داده و محدودیت آزمایش
ده کالا شامل متن فارسی، برند، دسته، قیمت، موجودی، tag، offer تو‌در‌تو و metadata منعطف هستند. قیمت‌ها عدد صحیح فرضی و بدون واحد پول‌اند. دادهٔ نمونه برای آموزش query است؛ از آن برای benchmark، تصمیم موجودی واقعی یا نتیجه‌گیری دربارهٔ latency production استفاده نکن.

## پاک‌سازی آزمایش

اگر تمام تمرین‌ها تمام شد و index نمونه را دیگر نمی‌خواهی، فقط روی sandbox این درخواست را اجرا کن:

~~~http
DELETE /products-lab-v1
~~~
