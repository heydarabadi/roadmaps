# Chapter 05 — Data and Caching

[فارسی](../../../fa/system-design/05-data-and-caching/README.md)

This chapter treats data storage as a workload decision. It covers relational and NoSQL models, cache design, freshness, partitioning, and higher-level patterns for separating reads and writes or coordinating data changes.

## Topics

- [Databases](16-databases/README.md)

## Learning outcome

You should be able to select a source of truth, model the read/write workload, and specify the consistency, freshness, and recovery properties a cache or data pattern requires.
