# سازهٔ زبانی درست — Use the right constructs


> **زبان:** [نسخهٔ انگلیسی](../../../../../../en/software-design-and-architecture/01/clean-code/topics/right-constructs/README.md)

## هدف درس

بتوانی مسئلهٔ این اصل را تشخیص بدهی، آن را در کد به‌کار ببری، trade-off را توضیح بدهی و در آزمون از نتیجه دفاع کنی.

## آموزش دقیق

سازهٔ زبان، قصد را دقیق و حالت نامعتبر را کم می‌کند: enum برای حالت محدود، collection برای چند مقدار، immutable type برای value، Result برای شکست مورد انتظار، exception برای شکست غیرمنتظره، pattern matching برای حالت‌های صریح و loop ساده برای پیمایش.

۱. حالت‌های معتبر و نامعتبر دامنه را فهرست کن.
۲. سازه‌ای انتخاب کن که اجازه ندهد مقدار نادرست بی‌صدا عبور کند.
۳. از idiom رایج زبان استفاده کن تا تیم syntax خصوصی نیاموزد.
۴. سازهٔ پیشرفته را تنها وقتی به‌کار ببر که ساده‌خوانی را بهتر می‌کند.

## مثال

اگر وضعیت سفارش رشتهٔ آزاد باشد، typo مثل “paied” ممکن است در دیتابیس بنشیند. enum آن را محدود می‌کند، ولی قاعدهٔ مجاز بودن تغییر از Paid به Shipped همچنان در مدل رفتار لازم دارد. تایپ‌کردن پول به Money نیز واحد را حفظ می‌کند و جمع دلار با ریال را قابل‌ردکردن می‌سازد.

## محدودیت

زبان ممکن است ویژگی‌هایی داشته باشد که تیم نمی‌شناسد یا tooling پشتیبانی نمی‌کند. generic یا macro پیچیده را به بهای یادگیری نامتناسب تحمیل نکن. کوتاه‌ترین syntax همیشه روشن‌ترین syntax نیست.

## تمرین

سه رشته/عدد خام در مدل پیدا کن. خطاهایی که ممکن است بیان کنند بنویس و نوعی پیشنهاد بده که ورودی نامعتبر را نزدیک مرز رد کند.

## نمونهٔ کد/قرارداد

~~~python
class OrderState(Enum):
    DRAFT = "draft"
    PAID = "paid"
    SHIPPED = "shipped"
~~~

## تمرین سنجش

نمونه‌ای از کد خودت یا یک پروژهٔ آموزشی انتخاب کن. مفهوم را در یک تغییر کوچک اعمال کن، آزمونی برای رفتار مرزی اضافه کن و با یک جمله ثبت کن که چه چیزی خواناتر یا امن‌تر شد.

## کوییز با پاسخ تشریحی

پیش از دیدن پاسخ، دلیل خودت را بنویس. پاسخ پیشنهادی باید با زمینه هماهنگ باشد؛ اگر گزینهٔ دیگری داری، trade-off آن را هم بیان کن.

1. **نوع دامنه‌ای چه فایده‌ای دارد؟**
   - پاسخ تشریحی: مقدارهای معتبر را نام‌گذاری می‌کند و بعضی خطاها را از زمان اجرا به زمان ساخت منتقل می‌کند.
2. **آیا enum انتقال state را تضمین می‌کند؟**
   - پاسخ تشریحی: نه؛ transition مجاز باید در رفتار مدل یا state machine کنترل شود.
3. **چرا idiom زبان مهم است؟**
   - پاسخ تشریحی: کد برای تیم آشنا و نگهداری‌پذیر می‌ماند و زبان خصوصی ساخته نمی‌شود.
