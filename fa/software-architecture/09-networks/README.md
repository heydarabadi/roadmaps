# فصل ۹: شبکه و ارتباطات

معمار برای تصمیم دربارهٔ latency، timeout، امنیت انتقال، مرزبندی شبکه، درگاه‌ها و عیب‌یابی باید مسیر درخواست را بفهمد. مدل‌های لایه‌ای ابزار تفکر و تشخیص‌اند؛ شبکهٔ واقعی همیشه منظم و بدون استثنا مطابق نمودار آموزشی نیست.

## تمرین فصل

مسیر یک درخواست HTTPS را از مرورگر تا سرویس و پایگاه داده ترسیم کن. برای هر مرز بگو کدام خطا، timeout یا سیاست امنیتی ممکن است رخ دهد.

منابع: [مرور HTTP در MDN](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Overview)، [OSI در AWS](https://aws.amazon.com/what-is/osi-model/).
