# زمان ثابت O(1)

> مسیر: [فصل ۱ — پایه‌ها و تحلیل الگوریتم](../readme.md) · پیش‌نیاز پیشنهادی: فصل ۱ و مبانی برنامه‌نویسی · [English](readme.en.md)

## پیش‌نیازها و نقشهٔ ذهنی

حلقه، دسترسی index و رشد تابع. ابتدا مفهوم را به‌عنوان یک قرارداد ببین، سپس نمایش حافظه و عملیات را دنبال کن. هدف حفظ‌کردن نام نیست؛ باید بتوانی برای یک ورودی کوچک، state را بعد از هر گام بنویسی.

## ایده از پایه

O(1) می‌گوید تعداد عملیات با بزرگ‌شدن n در مرتبهٔ ثابت می‌ماند. این مقدار می‌تواند 1 یا 1000 عملیات باشد؛ constant factor حذف می‌شود ولی روی latency عملی اثر دارد.

## مدل، قرارداد و ناوردا

عملیات باید تحت مدل مشخص واقعاً مستقل از n باشد. دسترسی آرایه با index معمولاً O(1) است چون آدرس محاسبه می‌شود؛ جست‌وجوی HashMap میانگین/expected O(1)، اما worst-case ممکن است O(n).

ناوردا (invariant) جمله‌ای است که در تمام مراحل الگوریتم باید درست بماند. نوشتن آن پیش از کدنویسی، هم به اثبات درستی کمک می‌کند و هم خطاهای مرزی را آشکار می‌سازد.

## الگوریتم یا عملیات گام‌به‌گام

مثلاً خواندن `A[k]`، افزایش counter، یا swap دو خانه تعداد ثابتی primitive operation دارد. اگر index باید با جست‌وجوی قبلی پیدا شود، آن پیش‌مرحله را جدا حساب کن.

در پیاده‌سازی واقعی، قرارداد ورودی/خروجی را دقیق تعریف کن: رفتار ورودی تهی، مقدار تکراری، عنصر پیدا‌نشده و ظرفیت تمام‌شده باید روشن باشد.

## اجرای حل‌شده با ردگیری

برای یافتن آخرین عنصر، `A[n−1]` O(1) است؛ پیمایش همه تا رسیدن به آخر O(n). هر دو «رسیدن به آخر» هستند اما الگوریتم و دسترسی متفاوت‌اند.

برای تمرین، جدولی با ستون‌های «گام»، «اندیس/اشاره‌گر»، «بخش فعال»، «تغییر state» و «دلیل» بساز. این روش به‌خصوص برای الگوریتم‌های درجا و تقسیم‌و‌غلبه جلوی پرش ذهنی را می‌گیرد.

## چرا درست است؟

برای ادعای constant، تعداد operationها را با n مقایسه کن. اگر loop، پیمایش collision chain یا کپی dynamic array متناسب n رخ می‌دهد، ادعای worst-case O(1) درست نیست.

اثبات معمولاً سه بخش دارد: (۱) آغاز—ناوردا پیش از نخستین گام درست است؛ (۲) نگهداری—هر گام آن را حفظ می‌کند؛ (۳) پایان—شرط توقف همراه invariant جواب موردنیاز را نتیجه می‌دهد. اگر یکی از این سه بخش نامشخص است، هنوز درک الگوریتم کامل نشده است.

## تحلیل زمان و حافظه

O(1) زمان معمولاً O(1) فضای auxiliary هم دارد، اما یکی از دیگری نتیجه نمی‌شود. ساخت hash در resize O(n) فردی است و append سرشکن O(1) است؛ واژهٔ amortized را دقیق ذکر کن.

در Big-O ورودی را تعریف کن (مثلاً n تعداد عناصر)، نوع حالت را نام ببر (بهترین/میانگین/بدترین)، و فضای کمکی را از حافظهٔ خود ورودی جدا کن. مرتبهٔ رشد زمان واقعی بر حسب ثانیه نیست؛ cache، تخصیص حافظه و ثابت‌های پیاده‌سازی هم اثر دارند.

## کاربرد واقعی و انتخاب مناسب

index lookup، stack top، queue endpoint و heap peek. در سیستم زمان واقعی، بدترین‌حالت تضمین‌شده مهم‌تر از average ثابت است.

پیش از انتخاب بپرس: چه عملیاتی پرتکرارند؟ آیا ترتیب مهم است؟ دادهٔ ورودی چه اندازه است؟ آیا محدودیت حافظه، latency بدترین‌حالت یا thread-safety داریم؟ ساختار خوب برای workload نامناسب می‌تواند انتخاب بدی باشد.

## خطاهای رایج و edge caseها

ثابت را با «لحظه‌ای/سریع» اشتباه نکن. `A.contains(x)` O(1) نیست. hash lookup را average/expected گزارش کن. حجم دادهٔ ثابت برای workload خاص، complexity asymptotic را حذف نمی‌کند.

حالت‌های مرزی را جداگانه بررسی کن: ورودی خالی، یک عضو، همهٔ اعضا برابر، هدف غایب، حداقل/حداکثر مقدار و اندازهٔ بزرگ. سرریز عدد صحیح در محاسبهٔ اندیس/ظرفیت نیز بسته به زبان مهم است.

## تمرین‌های مرحله‌ای

۱) access index و search را مقایسه کن. ۲) کدام operationهای dynamic array O(1) amortizedند؟ ۳) چرا wall-clock یک عملیات O(1) ممکن است از دیگری بسیار بیشتر باشد؟

برای هر تمرین، اول پاسخ ساده و درست بنویس، بعد پیچیدگی را حساب کن، سپس edge case اضافه کن. تمرین را با دست‌کم یک ورودی کوچک ردگیری کن و خروجی را با انتظار مستقل مقایسه کن.

## آزمون جامع با پاسخ تشریحی

ابتدا پاسخ‌ها را نخوان؛ جواب را با استدلال بنویس، سپس توضیح را مقایسه کن.

1. **پرسش:** O(1) به چه معناست؟
   **پاسخ تشریحی:** رشد تعداد عملیات مستقل از n تا یک کران ثابت.
2. **پرسش:** آیا یعنی یک عمل؟
   **پاسخ تشریحی:** خیر؛ تعداد ثابتی می‌تواند بزرگ باشد.
3. **پرسش:** hash lookup تضمین worst O(1) دارد؟
   **پاسخ تشریحی:** معمولاً نه؛ اغلب average/expected O(1).
4. **پرسش:** append همیشه O(1) فردی؟
   **پاسخ تشریحی:** نه؛ resize می‌تواند O(n) باشد؛ سرشکن O(1).
5. **پرسش:** access با index آرایه؟
   **پاسخ تشریحی:** در مدل معمول O(1).
