# فصل ۵: معماری امنیت

امنیت مجموعه‌ای از کنترل‌های پراکنده نیست؛ باید از دارایی‌ها، مرز اعتماد و تهدیدها آغاز شود و در هویت، API، داده، استقرار، پایش و پاسخ‌گویی به رخداد حضور داشته باشد. هدف، کاهش ریسک قابل‌قبول برای کسب‌وکار است.
