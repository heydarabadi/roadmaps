# طرح دورهٔ خودبسندهٔ Redis

## نیت و دلیل

READMEهای فعلی ۳۵ موضوع و ۱۰ فصل را معرفی می‌کنند، اما بیشترشان مرور کوتاه هستند. هدف این بازنویسی آن است که خواننده از آشنایی صفر با Redis تا استفادهٔ مطمئن در پروژه‌های کوچک و فهم trade-offهای production پیش برود و برای فهم درس‌های پایه و میانی به مقاله یا دورهٔ بیرونی نیاز نداشته باشد.

## مخاطب و فرض‌ها

- مخاطب با مفاهیم سادهٔ برنامه‌نویسی، terminal، client/server و JSON آشناست؛ Redis را از صفر شروع می‌کند.
- مثال‌های اجرایی با redis-cli و Docker نوشته می‌شوند تا از وابستگی به یک زبان برنامه‌نویسی جلوگیری شود.
- هدف یادگیری خودبسنده است، نه تضمین تسلط عملی بدون اجرا و تمرین. فرمان‌ها باید در یک محیط آزمایشی اجرا شوند.
- خط پایه، Redis Open Source خانوادهٔ 8 است؛ تفاوت نسخه‌ها و قابلیت‌های Cloud/Enterprise کنار درس مربوطه مشخص می‌شود.

## نتیجهٔ مورد انتظار

پس از پایان مسیر، خواننده باید بتواند:

1. Redis و نقش آن را در کنار پایگاه دادهٔ اصلی توضیح دهد.
2. براساس query، ساختار دادهٔ مناسب را انتخاب و keyspace قابل نگهداری طراحی کند.
3. از TTL، شمارنده، cache، session، صف، Streams و Pub/Sub با درک تضمین‌ها استفاده کند.
4. رفتار تراکنش، WATCH، Lua، persistence، replication، Sentinel و Cluster را با محدودیت‌هایشان شرح دهد.
5. Redis را با حداقل دسترسی و شبکهٔ امن، حافظهٔ قابل پایش، backup/restore و برنامهٔ بازیابی طراحی کند.
6. برای یک workload نمونه طرح کوتاه شامل ظرفیت، failure mode، metric و trade-off بنویسد.

## شکل محتوا

ساختار کنونی ۱۰ فصل و ۳۵ پوشهٔ موضوعی حفظ می‌شود تا لینک‌های موجود نشکنند. README اصلی تبدیل به راهنمای مسیر و نقشهٔ پیشرفت می‌شود. به هر README موضوعی یک درس کامل افزوده می‌شود با این ترتیب:

1. پیش‌نیازها و واژه‌نامهٔ همان درس
2. توضیح مفهومی با یک مدل ذهنی و در صورت نیاز دیاگرام متنی
3. شرح مرحله‌به‌مرحلهٔ دستورها و خروجی مورد انتظار
4. مثال کوچک قابل اجرا و walkthrough خط‌به‌خط
5. کاربرد، مرز مناسب‌بودن، trade-off و failure mode
6. اشتباه‌های رایج و روش عیب‌یابی
7. تمرین هدایت‌شده، تمرین مستقل و معیار بررسی پاسخ
8. کوییز با پاسخ توضیحی در بخش بازشونده
9. منابع فارسی و انگلیسی تکمیلی و یادداشت تفاوت نسخه

دستورهایی که ممکن است داده را حذف کنند یا سرویس را تغییر دهند، با برچسب آزمایش محلی می‌آیند. خروجی فرمان‌ها نمونهٔ آموزشی است و به‌عنوان مشاهدهٔ اجرای واقعی معرفی نمی‌شود.

## پروژه‌های پایانی

در کنار درس‌های موضوعی، سه لَب end-to-end اضافه می‌شود:

- **Cache محصول:** cache-aside، TTL، invalidation، cache miss، stampede و fallback.
- **صف رویداد سفارش:** List در برابر Streams، گروه مصرف‌کننده، pending، ack، retry و idempotency.
- **سرویس production فرضی:** ACL/TLS، maxmemory، persistence، replication/HA، metric، backup و restore drill.

هر پروژه نیازمندی، گام‌ها، پاسخ نمونه، edge case و rubric ارزیابی خواهد داشت.

## منابع و دقت فنی

- آموزش اصلی به فارسی و تا جای ممکن خودبسنده است؛ منابع بیرونی مکمل‌اند، نه پیش‌نیاز.
- مستندات رسمی Redis مرجع commandها و ویژگی‌های وابسته به نسخه می‌مانند.
- هر تجربهٔ شرکت‌محور فقط وقتی «واقعی» نامیده می‌شود که منبع منتشرشده داشته باشد و مشخص شود گزارش فروشنده/مشتری است. سایر سناریوها صریحاً تمرین آموزشی‌اند.
- منابع فارسی کم‌پوشش علامت می‌خورند؛ لینک جست‌وجو به‌عنوان مقالهٔ خوانده‌شده جا زده نمی‌شود.
- اگر قابلیت به Redis 8، Stack/Module، Cloud یا Enterprise وابسته باشد، شرط نسخه در همان درس می‌آید.
