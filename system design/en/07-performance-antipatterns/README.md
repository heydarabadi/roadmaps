# Chapter 07 — Performance Antipatterns

[فارسی](../../07-performance-antipatterns/README.md)

This chapter names recurring design and implementation choices that look convenient but create bottlenecks under realistic traffic. It teaches you to connect symptoms such as queue growth, inefficient queries, chatty calls, and unbounded concurrency to measurements and fixes.

## Topic

- [Performance antipatterns](23-performance-antipatterns/README.md)

## Learning outcome

You should be able to form a testable bottleneck hypothesis and verify the effect of a targeted change using representative load and end-to-end measurements.
