# Chapter 7: APIs and Integration

An integration design is a contract plus its behavior under change and failure. These lessons compare HTTP APIs, GraphQL, gRPC, messaging, and workflow technologies.

## Chapter outcome

Choose a communication model based on response needs, coupling, consistency, and operational ownership; make retries and schema evolution explicit.
