## Roadmap scope and version

The source is the [Go Developer roadmap](https://roadmap.sh/golang) and its [PDF](https://roadmap.sh/pdfs/roadmaps/golang.pdf). The request displayed system-design in its link label but the actual destination was /golang; this course follows the Go destination. The checked toolchain release is Go 1.27.4, released on November 10, 2026; the module language baseline is Go 1.27. See the [official release history](https://go.dev/doc/devel/release).

The local lessons cover the roadmap without requiring continuous internet access. External links are optional references for current specifications, release details, and original engineering papers. The bibliography is selected rather than an exhaustive reading of every web page.
